# Онтология продукта для команды ИИ-агентов

Материалы к докладу «ГенИИ в продуктовом управлении. Работа с виртуальными сотрудниками» на митапе ГК Софтлайн «ИИ в разработке ПО», 20.10.2026. Николай Тржаскал, директор по развитию технологий ИИ, FabricaONE.AI.

**Онтология продукта** — файлы в папке `product/` рядом с кодом. В них записано, из чего состоит продукт, как связаны его части и какие решения и требования действуют, со ссылками на код. Агент берёт из онтологии нужные записи и идёт в код по ссылкам. Скрипты сверяют онтологию с кодом и проверяют изменения агента по требованиям.

## С чего начать

Порядок шагов описан в [02_ontology_kit/README.md](02_ontology_kit/README.md). Коротко:

```
mkdir product
cp 02_ontology_kit/tools/*.py 02_ontology_kit/ontology_template.md product/
```

Затем сильная модель собирает онтологию по первому промпту из [build_prompt.md](02_ontology_kit/build_prompt.md), а проверку ставят в CI:

```
python3 product/check.py
python3 product/check_change.py --base origin/main
```

Скриптам нужны Python 3.9 или новее и git, других зависимостей нет.

Шаблон, промпты, правило для агента, задания ролям и скрипты написаны на английском: их читает агент. Пояснения для людей на русском.

## Что проверено

Замеры доклада сделаны на моделях Claude. Скрипты проверены на ERPNext и на небольшом проекте на TypeScript. Раскладка моделей для других семейств составлена по открытым бенчмаркам на 19.10.2026, работу команды на них я не проверял.
